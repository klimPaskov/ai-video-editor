# ADR 0008: Visual references require contract sync

- Status: Accepted starting decision
- Date: 2026-09-04

## Decision

Later screenshots are added through a manifest and mapped to screen specifications. A visual reference change is incomplete until affected specs, tests, tasks, and traceability are updated.

## Consequences

- References guide simplicity and composition.
- References do not override required behavior or security.
- Protected branding and exact layouts are not copied.
