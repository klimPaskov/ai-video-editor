# ADR 0009: Lossless-first media

Status: accepted product requirement

## Decision

Default to verified lossless capture, intermediates, and a FFV1/PCM master. Keep lower-quality playback and sharing profiles explicit and separate. Apply docs/44_LOSSLESS_MEDIA_POLICY.md.

## Verification

Implement the mapped tests and record evidence during the relevant phase. This decision is not proof that code exists.
