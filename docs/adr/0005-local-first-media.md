# ADR 0005: Local-first media

- Status: Accepted starting decision
- Date: 2026-09-04

## Decision

Store recordings, imported media, proxies, transcripts, projects, previews, and exports locally by default.

## Consequences

- Codex receives only the minimum selected context needed for a task.
- Raw full-resolution media is not uploaded by default.
- Local B-roll is supported before remote stock services.
- Project deletion and cleanup are explicit.
