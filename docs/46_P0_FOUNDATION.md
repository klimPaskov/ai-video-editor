# P0 foundation slice

P0-01 through P0-08 are accepted in [the guarded result](workflow/results/P0.json), bound to published revision `8fe7c4bcbe8511ac8772c043ff023b15075ad823`. P1 was subsequently accepted. This document preserves the accepted foundation scope and remaining product limits.

## Scope and evidence boundaries

The foundation establishes an npm workspace with strict TypeScript, linting and formatting, a media package and domain contracts, schema/example validation, a guarded phase-result writer, public-source auditing, and synthetic FFV1/PCM round-trip fixtures. The checks must run through the documented repository command and report actual failures. Research and exact dependency observations are in [P0 foundation research](research/P0_FOUNDATION.md).

Synthetic fixtures compare decoded video and audio against canonical raw samples, including an intentionally edited canonical case. Tested encoder boundaries do not prove native capture, renderer precision, hardware access, real-time throughput, or the full master-export path. Capture adapters and unsupported precision profiles must remain unverified until their own evidence exists. Default preview, capture, intermediate and master requirements remain governed by [the lossless policy](44_LOSSLESS_MEDIA_POLICY.md).

An isolated Linux desktop is now available through Docker 28.5.2. The environment runs as an unprivileged guest user, mounts no host files or devices, drops capabilities, and exposes only authenticated loopback VNC. A dedicated Electron 44.2 / Playwright 1.63.0 compatibility probe passed with Chromium sandboxing enabled. A fresh `probe-setup` followed by `probe` also passed. Computer use inspected native Xmessage and Electron windows through TigerVNC and confirmed visible input responses. A user Escape interrupted the later computer-use close step; no clean computer-use close is asserted. Provisioning and probe instructions are in [the desktop test README](../tests/desktop/README.md).

This evidence establishes infrastructure, not the product. Separately, the actual packaged Electron 44.2 bootstrap under `apps/desktop` passed isolated Linux security, immutable synthetic import, two-frame equality/seek and library-reopen tests. The renderer's Linux `/proc` evidence confirmed sandboxing. Computer use through native TigerVNC selected the source card and advanced from red at zero to green at 0.500 seconds. No user video has been imported. Windows devices and installers, virtual capture fixtures, audio listening, real Codex editing, and production render/review/export remain unverified. The current user instruction authorizes host Docker provisioning and a native viewer; product builds and launches remain confined to the guest. VNC has no audio transport and its 24-bit display cannot establish high-precision media equality. The P0 audit and source publication passed; P1-P10 remain incomplete.

Public repository work must resolve and verify the authenticated owner, review staged paths and contents, and verify the remote commit under [the public-development policy](45_OPEN_SOURCE_DEVELOPMENT.md). The initial foundation, CI correction PR #1, isolated desktop PR #2, and reviewed native bootstrap PR #3 are published. The accepted source revision is `8fe7c4bcbe8511ac8772c043ff023b15075ad823`; Windows/Linux push and PR checks passed in runs `33952499182` and `33952514882`. Private footage, projects, tokens, logs, and generated acceptance evidence remain excluded. MIT licensing does not grant redistribution rights for runtime binaries, models, fonts, or supplied imagery.

## Actual native media prerequisite

ADR 0012 resolves the circular dependency between P0's native media gate and a shell previously deferred entirely to P1. P0-04/P0-06 now include only the actual packaged local product shell, typed validated IPC, native import, immutable managed media library, and bounded frame transport required to exercise synthetic media natively. The infrastructure probe cannot satisfy this gate. Full P1 shell/navigation/accessibility and P2 Codex, P3 project/draft/A/V playback, P4 capture, and later requirements remain separate acceptance work.

The append-only library preserves original files and managed source bytes; it is not project storage or an edit history. The initial verified frame adapter accepts native-dimension BGRA full-range GBR BT.709 SDR within explicit size limits, reorders channels without resampling, and creates no lossy preview. Other supported video imports are preserved with preview explicitly unavailable. Home import/library selection and frame seek are real bootstrap controls, not a substitute for the requested editor. Packaged local-protocol security, IPC foreign-window denial, source equality, native-size two-frame equality/seek, reopen and actual native interaction passed. Stronger same-runtime checks compared complete opaque nonuniform canvas buffers across seek and reopen using distinct source frames. Arbitrary alpha and display-compositing fidelity remain unverified. Separate master verification passed canonical decoded-sample equality; it does not establish a final-export UI. The bootstrap provides no audio playback or edits yet.

The changed foundation requirement is executable, reproducible validation with truthful evidence, rather than planning checks alone. Active task coverage now includes P0-07 and P0-08. Research links and the stale unsupported-WebSocket rationale have been corrected. Traceability distinguishes foundation checks from required native evidence.

The latest user workflow is now synchronized as Import → Magic Edit → Refine → Review → Export. ADR 0003 records that the current instruction supersedes the historical four-stage starting decision. Planning, workflow, P1 header task wording, user/UI/screen specifications, screen manifest, UI and screen schemas, examples, UI skill, native review prompt, routing guidance and reference correction notes now distinguish Edit from Review. S08 is Edit; revision comparison and S10 quality review are Review. The internal `qa` screen identifier is retained, but `qa` is no longer a project-stage value. Reference images and their manifest are unchanged.

The guarded tool manifest, tool schema, examples, Codex integration/catalog documentation and runtime skill now require `user_confirmation: none` for already authorized `active_draft` and `export_staging` work, including Magic Wand and `export.prepare`. Final export is still an explicit native user action unavailable to AI tools. Source deletion, cleanup, spending and publication remain explicit user actions. Native server approval events are distinct from application draft-edit authorization. The Codex integration document also now gives the current stdio rationale without the stale WebSocket maturity assertion.

`tests/foundation/test_workflow_contracts.py` checks five-stage enums, screen assignments, preserved QA screen identity, authorized tool policies and negative confirmation regressions. These are contract checks, not native interaction or real runtime tests. P1/P2 must still verify stage transitions preserve draft/undo state and a real authenticated turn edits the active draft without repeated approval. The isolated desktop removes the previous environment blocker; the compatibility probe does not replace those product checks.

Future loading must apply these mappings to historical project and UI state before validation; current five-stage Review values must not be remapped blindly.

Other domain schemas, timeline operations and source/media contracts remain unchanged by this workflow synchronization. No image assets were changed. The guarded P0 result now includes its spec-sync section after acceptance and remote revision verification.
