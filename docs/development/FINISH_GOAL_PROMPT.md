## The product, in one paragraph

A standalone Electron desktop video editor in which the AI does the editing. The user imports or records a video, presses one button, and Claude (through the user's own unmodified Claude Code CLI, signed in with their Claude account) cuts the video, adds motion graphics, captions and sound, and the user reviews and exports. Everything the AI does is an undoable, non-destructive draft transaction shared with manual edits. Source media is immutable. Codex and API-key providers remain alternatives. The interface must be extremely minimal: few things visible at once, the current step unmistakable.
