# UI references

This folder contains **20 original individual native-app screenshots**, not contact sheets.

- `screenshots/current/`: ten current native-app references
- `screenshots/previous/`: ten earlier desktop-app references
- `index.html`: offline viewer showing one full-size image at a time
- `manifest.json`: screen mappings, provenance, and file hashes
- `IMPLEMENTATION_NOTES.md`: mandatory corrections to the generated references
- `SCREEN_COVERAGE.md`: direct, partial, and specification-only coverage

Images are included at their original resolution and bytes. No image was cropped from a collage, relabelled as a real application screenshot, or treated as proof of working software. Earlier browser-app concepts and multi-screen montages are not part of this native-app workspace.
