# AI assistant

Open the assistant with the button at the top right of a project (it shows the connected service, for example **Claude**). Describe what you want, for example "cut the long pause after the introduction" or "speed up the part where I am typing".

## What it can do

The assistant edits through the same tools as the manual controls. It can read the project's timeline and transcript, split and cut ranges, restore footage, correct transcript words, add, change and remove zooms, and set speed. Each change is checked against the current draft, so it never edits a stale version, and each one can be undone. **Stop** ends a reply at any time.

The assistant cannot read or change files outside the project, run programs, or export.

## Connections

| Connection | Account | Billing |
| --- | --- | --- |
| Claude (default) | Your Claude account, through your installed Claude Code | Your Claude plan |
| Codex | Your ChatGPT account | Your ChatGPT plan |
| OpenAI, Gemini, DeepSeek | An API key you paste in Settings | Pay per use on that key; the app asks before sending a paid request |

Claude sign-in happens in Anthropic's own browser page through Claude Code, and the app never handles Claude credentials. Choose the model in Settings; the app shows only models your account offers.
