# P0: research, decisions, and repository foundation

Task IDs: `P0-01` through `P0-08`

Read all authoritative package files, current official documentation, and the `orchestrate-implementation`, `research-product`, and `spec-sync` skills. Research current stable Electron, Playwright, FFmpeg, local transcription, and Codex app-server contracts. Verify product reference claims through public sources. Establish strict projects, tests, schema validation, result writing, and a generated media fixture.

Do not build a static UI demo. Do not pin versions from memory. Record accepted or revised ADRs with reasons.

Apply ADR 0012: P0-04 and P0-06 include the minimum actual product packaged local shell, sandboxed typed IPC, native import, immutable managed media library, and bounded frame inspection. Build and launch only in the isolated guest. The library is not a project or draft. Keep full P1 navigation/accessibility, P2 Codex, P3 project/draft/A/V playback, and P4 capture acceptance in their existing phases. Unsupported frame color/precision paths remain explicitly unavailable without silent conversion.

Acceptance:

- repository checks run from one documented command
- all package schemas and examples validate
- a generated fixture probes and fully decodes
- the actual packaged product imports a synthetic fixture, preserves source bytes, reopens its library, and provides verified frame inspection/seek through typed IPC
- Playwright Electron and computer use inspect that native product path in isolation; the compatibility probe alone cannot satisfy this check
- current dependency and protocol versions are recorded
- `docs/workflow/results/P0.json` validates

Also read `docs/44_LOSSLESS_MEDIA_POLICY.md` and `docs/45_OPEN_SOURCE_DEVELOPMENT.md`. Create or verify the public `ai-video-editor` repository and publish the reviewed foundation. Record the exact remote commit or the real access blocker. Establish lossless round-trip fixtures and a capture-fidelity boundary before building media-dependent features.
