## P5-01 implementation

Auto Edit now offers an explicit Transcribe locally action with model-download progress, transcription progress, Stop, path-free polling, and a read-only word-timed transcript view. The first user-started run downloads the pinned Apache-2.0 `Xenova/whisper-base` q8 weights into application-private storage and verifies size and SHA-256 before inference. The app prepares a temporary mono 16 kHz float32 analysis proxy from verified managed media, keeps source audio off the network, and stores transcript plus independent silence evidence outside project baselines and drafts. The source, initial revision and active draft remain unchanged. Repeated active starts reuse their job; polling after a simulated timeout reuses the same job ID; a reopened project restores the cached transcript by source hash and model revision. See [P5 local-transcription research](../../research/P5_LOCAL_TRANSCRIPTION.md).
