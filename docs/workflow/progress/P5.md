The active acceptance phase remains P2. P2-02, P2-07 and P2-09 are open, so no P2 result is written. P5-01 was independently dependency-safe on the existing imported-source and typed IPC foundation.

## P5-01 implementation

Auto Edit now offers an explicit Transcribe locally action with model-download progress, transcription progress, Stop, path-free polling, and a read-only word-timed transcript view. The first user-started run downloads the pinned Apache-2.0 `Xenova/whisper-base` q8 weights into application-private storage and verifies size and SHA-256 before inference. The app prepares a temporary mono 16 kHz float32 analysis proxy from verified managed media, keeps source audio off the network, and stores transcript plus independent silence evidence outside project baselines and drafts. The source, initial revision and active draft remain unchanged. Repeated active starts reuse their job; polling after a simulated timeout reuses the same job ID; a reopened project restores the cached transcript by source hash and model revision. See [P5 local-transcription research](../../research/P5_LOCAL_TRANSCRIPTION.md).

## P5-02 text-correction slice

## P5-02 selected-word cut (complete, 2026-09-27)

The current working slice adds source/transcript selection, inclusive start/end word selectors and a `Cut selected words` action in Edit. Main checks the active project and Edit stage, validates both word IDs against one unchanged local transcript, maps the exact selected source-time interval to one continuous currently visible clip, and commits a `transcript_cut` ripple-delete record with both word identities and exact source/output times through the existing draft transaction store. The clip map refreshes from committed state, so shared Undo restores the pre-cut interval; Redo replays the same operation. The IPC request contains no filesystem path, and the source media and raw ASR transcript remain unchanged.
